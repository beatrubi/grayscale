# Grayscale

Between October 1st 2025 and September 30th 2026 I took one picture a day. See the full story on [fotistudio.ch/pages/grayscale](https://fotistudio.ch/pages/grayscale).

> Grayscale is the standard spelling in American English.
> Greyscale is the preferred spelling in British English and Commonwealth countries (using "grey" instead of "gray").

This repo contains the scripts I used to prepare the images and build an application.
